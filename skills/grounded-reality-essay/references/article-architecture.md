# Article Architecture

## 结构一：反常识解释型

适合题目：为什么 X 明明看起来很简单，普通人却很难做到？

1. **直接反转**：问题不在“懒/笨/没魄力”，而在被忽略的成本。
2. **具体场景**：写一个人真正要做的第一步。
3. **隐性步骤**：拆成 4–7 个步骤。
4. **成本账**：时间、钱、机会成本、失败成本。
5. **为什么替代方案更合理**：解释“看似保守”的选择。
6. **反方**：承认个体差异，避免一刀切。
7. **机制句**：选择不是脱离条件发生的。

## 结构二：阶层认知差型

适合题目：为什么 A 群体很难理解 B 群体？

1. 一个很小的生活细节。
2. 解释双方默认前提不同。
3. 列出 3 个“默认资源”：钱、家庭支持、城市基础设施/信息。
4. 指出双方并非一定恶意，而是经验样本完全不同。
5. 写“同一句建议，在两套资源条件下意味着不同动作”。
6. 结尾：认知差首先是生活样本差。

## 结构三：制度通道型

适合题目：学历、房产、证书、组织身份到底有什么用？

1. 不从“价值”谈，先从“哪些门会自动打开/关闭”谈。
2. 写制度如何降低交易成本或审查成本。
3. 写没有资格的人如何用额外时间、金钱、人情替代。
4. 写资格的局限，避免神化。
5. 结尾：资格的价值常常不是让你变聪明，而是让系统愿意先让你进门。

## 结构四：文化变迁型

适合题目：某种文化/产品为什么衰落或复兴？

1. 先写它过去解决了什么需求。
2. 今天这个需求是否还存在？
3. 替代品是否更便宜、更快、更贴合新生活？
4. 原有价值观是否仍和今天的激励结构兼容？
5. 如果“复兴”，是大众复兴还是小众聚集被互联网放大？
6. 结尾：文化不是因为“传统”而活，而是因为继续解决人的问题而活。

## 段落级写法

一个有力段落通常包含：

- 判断：这一步真正卡住的不是能力，而是现金流。
- 具体化：你要先连续三个月没有收入，还要承担房租和通勤。
- 机制：所以风险厌恶不是性格缺陷，而是失败缓冲太薄。
- 回扣：这就是为什么“辞职创业”对两个人不是同一个动作。

## 标题公式

避免纯情绪标题，优先：

- 为什么 X 看起来很简单，真正做起来却这么难？
- X 真正值钱的，不是 A，而是 B
- 很多人把 X 理解反了：真正的门槛是 Y
- 普通人面对 X，最容易低估的其实是这三笔成本
- 同一句“去试试”，对不同的人为什么完全不是一回事？
