# Fact-checking Rules

这个 skill 的强项是机制推理；最容易出问题的地方，也是“一个很顺的故事让未经核实的事实看起来很真”。因此必须把事实纪律写进流程。

## 1. 四类句子

### Fact / 事实
可被外部资料验证。

例如：某年某政策、某公司股权结构、某地区历史产量、某项法律规则。

**要求：**重要事实必须有可靠来源；时效性事实优先官方或一手资料。

### Observation / 观察
来自用户提供、作者亲历、公开采访或个案。

**要求：**不要从一个个案直接推成“所有人”。

### Inference / 推断
从事实推出的解释。

**要求：**使用“可能、一个重要原因是、这会提高……概率”等语言；除非因果证据充分，不写成必然。

### Value / 价值判断
“公平/不公平、值得/不值得、好/坏”。

**要求：**和事实分开写。

## 2. 必须外查的高风险内容

以下内容只要是文章的重要论据，就应搜索核验：

- 历史制度、具体年代、产量、死亡率；
- 公司股权、治理结构、财务数字；
- 政策、法律、税费、监管；
- 国际政治、宗教人口比例；
- 医学、健康、心理学；
- 犯罪案件和具体人物责任；
- 任何“XX%”“三分之二”“所有/从来没有”等强断言。

## 3. 来源优先级

1. 官方文件 / 法律文本 / 公司公告 / 学术论文
2. 权威媒体与专业机构
3. 可靠数据库、行业报告
4. 高质量二手文章
5. 社交媒体与个人经验（只能做线索或观察）

## 4. 数据不确定时怎么写

错误：

> 当时亩产就是 87 公斤，所以……

更稳妥：

> 有历史统计显示，部分地区当时的亩产远低于今天。具体数字受地区、年份和统计口径影响，但这足以说明：开出一亩地不等于立刻获得稳定粮食收益。

机制保留，脆弱数字降权。

## 5. 类比不是证据

“古代土地 ≈ 今天房产”“开荒 ≈ 创业”可以帮助理解，但不能由此推出两者在法律、市场和风险上完全相同。

类比之后至少补一个差异：

> 当然，今天的住房有金融属性、租赁市场和更强的流动性，不能与古代土地直接等同；这里比较的只是‘稳定资产如何影响他人对你长期性的判断’。

## 6. 完成标准

文章发布前，应能回答：

- 哪 3 个事实最关键？
- 它们分别来自哪里？
- 如果这 3 个事实中有 1 个被证伪，核心机制还成立吗？

如果一条脆弱事实倒塌会让整篇文章倒塌，就说明文章对故事/数字依赖过高，需要重写机制。
